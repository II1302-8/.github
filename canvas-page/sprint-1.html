Sprint goal

A user should be able to view berth availability as well as details about specific berths.

Sprint backlog

  • User story 1:
    As a visiting boater, I want to see which berths are free at a glance on a harbor map, so I can head straight to an open spot without walking the dock.
    • User sub-story 1:
      As a visiting boater, I want the map to show the current / live state of berths when I open it, so I trust that what I see is real and not stale. 
  • User story 2:
    As a visiting boater, I want to tap a berth to see its details, so I can decide whether it suits my boat before heading over.
