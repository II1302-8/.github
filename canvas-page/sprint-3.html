Sprint goal

By the end of the sprint, the residuals from sprint 2 should be resolved, and there should be a box to encapsulate the IoT device, with a QR-code for the harbor master to adopt the node into the system.

Sprint backlog

  • As a harbor master I would like the ability to view all data that is relevant to me, so that I can perform my job with ease
  • As a harbormaster I would like to be able to adopt new nodes into the system so that I can perform maintenance
  • As a visiting boater I want to be able to physically see the status of the berth, so that I know if it is available without checking the website
  • As a harbor master I want the sensors to be waterproof, so that it is sustainable
